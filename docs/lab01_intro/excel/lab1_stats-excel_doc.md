# Excel basics

Objectives:

* Analyzing GDP per capita for World Countries.
* Analyzing by region

## Setup

Options:

* A. Install Excel app: https://td.usnh.edu/TDClient/60/Portal/KB/ArticleDet?ID=854
* B. Use Excel in the browser
* C. Use Google Docs in the browser

You can also use other spreadsheet applications (e.g. Numbers, OpenOffice, etc.)
In each case, you will submit a XLSX file.

**IMPORTANT:** If you're working with Excel, be sure to save to XLSX after opening a CSV file, of you will lose data!

## Data

* data is provided in the "data" directory
* For reference, these are the sources:
    * [Development Indicators](https://databank.worldbank.org/source/world-development-indicators)
        * [Popular indicators](https://databank.worldbank.org/indicator/SP.POP.TOTL/1ff4a498/Popular-Indicators)
    * [Happiness Data](https://www.worldhappiness.report/data-sharing/)
    * [Regions](https://github.com/lukes/ISO-3166-Countries-with-Regional-Codes/blob/master/all/all.csv)
