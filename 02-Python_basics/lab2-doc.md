## Instructions

* Two files are provided in "files":
    - problems
    - prompt

* Use these to generate source code.
    - use Gemini or another model of your choice.
    - you are free to modify the prompt as you see fit.

* Run the tests in VSCode using integrated testing
    - see: https://code.visualstudio.com/docs/debugtest/testing 

* Get in groups (2-3) and discuss the source code.  
    - take it one function at a time
    - look at the function and the test

* Only one person needs to submit.  
    - They should add the other names at the TOP of the doc.
    - The person who submits will be considered the "leader" for this submission.
    - The leader should rotate.  Each person should be leader ~4 times per semester.

## Submission:

### 1. The "Final" Source Code & Test Report

* **The `.py` (or `.ipynb`) file:** The final version of the code they generated and potentially edited.
* **A screenshot of the Test Explorer:** A visual confirmation that all tests passed (the "Green Checkmarks").

### 2. The "Prompt Evolution" Log

* **The initial prompt:** What they started with.
* **The iterations:** If the first code failed the tests, what did they change in the prompt to fix it?
* **Reflection:** A 2-3 sentence summary of *why* the AI failed initially (e.g., "The AI didn't handle the empty list case correctly, so I had to explicitly mention edge cases").

### 3. The Group Discussion Synthesis

"Code Commentary." Table or list.  For each function:

* Function name
* What the Test specifically checked
* One thing the group learned/noticed

#### Aggregating:

**Submit a single ZIP file containing:**
1. **Code:** Your final Python file.
2. **Verification:** A screenshot of your VSCode "Testing" panel showing all tests passed.
3. **AI Log:** A short PDF/Markdown file showing the prompts you used and a brief summary of your group's discussion on the functions.
