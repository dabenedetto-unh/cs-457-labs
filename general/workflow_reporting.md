# Workflow and reporting

* Using AI:
    - use Gemini or another model of your choice.

## Workflow

* Generally, I will provide you with information about the problems you are to solve.
* Then, you go through the following process (for each function)
    - you can skip steps as you see fit, based on your experience.
    - you can collaborate, or work individually and compare results later, but you need to have at least some discussion with peers.

### PLANNING / PSEUDOCODE:

* first, try sketching out pseucode
    - how would you instruct a computer to solve this?
    - think about inputs, logic, and outputs.
    - use your own language, but try to be precise

### CODE / TESTS

* next, try writing some code by hand
    - implement one function
    - and at least one test for that function
* Use AI
    - you can use AI to generate code and tests
    - or, you can use AI to review the code and tests you've written.

### TRACING / DISCUSSION

* for each test, trace the execution of your code.  
    - if you used AI, check that you understand each line.
* Now you should discuss your results with your peers.  
    - take turns explaining functions and tests to one another.

## Submission

Each INDIVIDUAL submits these three files:

* **single-file report**, including:
    - your initial pseudocode for 2-3 problems
    - information about the model and prompt(s) you used
    - summary of group discussions.
    - link to OneDrive folder:
        * **code file(s)**: python code and tests

Note:

* the group only needs to prepare one discussion summary 
    - but each individual in the group should add this to their report

### Grading Rubric (100 Points)

---
| Criteria | Points | Proficient (Full Credit) | Developing (Partial) |
| --- | --- | --- | --- |
| **Logic & Pseudocode** | 30 | Precise, human-language logic for 2–3 problems written *before* AI code. | Pseudocode is missing, or is just a copy of the final Python code. |
| **AI Documentation** | 20 | Explicitly names the model and lists the prompts used to generate stubs/tests/solutions. | Mentions AI but doesn't provide the actual prompts or iterations. |
| **Code & Testing** | 30 | Python code is complete and includes the AI-generated test stubs. | Code is incomplete or missing the required test cases. |
| **Group Reflection** | 20 | Summary clearly details what the group compared or learned during the checkpoints. | Summary is extremely brief (e.g., "we compared and it was fine") or missing. |
